Официальный репозиторий APK-сборок приложений **VARKYNTH** — независимого разработчика.

## Как скачать

1. Открой раздел [**Releases**](https://github.com/varkynth-official/apks/releases)
2. Выбери нужное приложение и версию
3. Скачай файл `*.apk` по прямой ссылке
4. На телефоне разреши установку из этого источника и установи

## Ссылки на релизы

Прямая ссылка на файл из релиза выглядит так:

```
https://github.com/varkynth-official/apks/releases/download/<версия>/<файл>.apk
```
